# Extended typography scale

Contract ID: da.typography.extended.v1 Status: proposed additions; platform reflow pending

Anton headings and Archivo reading/UI text extend the existing approved families. Live Squarespace Proxima Nova remains intentional. Use style names by role and do not infer HTML heading rank from visual size.

- Heading/Page: Anton 48/52
- Heading/Component: Anton 28/34
- Heading/Subsection: Anton 24/30
- Body/Large: Archivo 20/32
- Body/Small: Archivo 14/22
- UI/Caption: Archivo 12/18
- UI/Numeric: Archivo 16/24

Avoid fixed-height text boxes. Preserve content at 320px, enlarged text and text-spacing overrides. Do not use font weight or size as the sole indicator of state. These additions are system proposals, not observed site CSS.
