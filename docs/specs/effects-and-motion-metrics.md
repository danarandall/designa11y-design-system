# Effects and motion metrics

Contract ID: da.effects-motion-metrics.v1 Status: proposed additions; existing Card lift approved

Surface and Overlay shadows use brand Aubergine alpha; visible semantic borders still provide meaningful boundaries. Decorative blur never applies to essential content. Reduced-transparency and forced-color modes use opaque legible surfaces and system boundaries.

Motion metric tokens store milliseconds: feedback 120, selection 100, disclosure 160, overlay 140. They are proposed interface recipe values; do not claim they came from live CSS. No semantic update waits for motion. Retain static reduced-motion alternatives, cancellation/retargeting and user control for persistent effects.

Acceptance: visual/thematic review, final-composite contrast, forced colors, low-power behavior and runtime preferences. No effect is accessibility certification.
