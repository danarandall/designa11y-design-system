# Interface icons

Contract ID: da.icons.v1

24 original vectors plus existing Close and ArrowRight masters. Use instance swap on icon controls, never a variant per icon. 24px nominal size, 2px stroke, semantic text/primary ink; preserve geometry. Match one meaning to one icon. Label icon-only controls explicitly. Hide decorative glyphs from accessibility APIs. Do not infer a usable target from a 24px glyph; the control remains at least 44px.

Names are stable; SVG exports are configured. Pixel and optical review at 16/20/24px remains pending. No Prime icons copied.
