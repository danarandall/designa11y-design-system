# DesignA11y Design System — v0.1.0-beta.1

Published October 18, 2026 by Dana Randall (individual creator).

Figma Community: https://www.figma.com/community/file/1693787144054932231

A reference design system for humans and AI agents: brand foundations, reusable components, responsive patterns, native Specs and public machine-readable contracts. Adapt the reference identity using central variables, shared styles, component property defaults, asset sources and guided brand decisions.

## Included

- Brand identity, background guidance, patterns and social/video/packaging studies.
- Color, typography, layout, shape, effects and motion foundations.
- Reusable interface components and responsive patterns.
- Public Specs and JSON contracts, an experimental adaptation skill and a no-install starter prompt at the beginning of Start here.
- Refinements from partial adaptation tests: preserved component text overrides, content-growing footers, shared image sources, longer palette-name handling and bounded research/checkpoint guidance.

## Known limits

Full fresh-copy adaptation and broad state/theme validation remain incomplete. Artwork and motion may need explicit replacement or manual work. Packaging and video are design studies. Figma designs and accessibility requirements are not runtime conformance certification. Implementations need keyboard, assistive-technology and other relevant testing. Source IDs are references; discover IDs in your own copy. Automatic Figma/Git synchronization is not provided.

## Start

Duplicate the Figma file. Open Start here. Copy the starter prompt or install the optional skill, connect a compatible assistant to your copy, define your brand profile, then apply and validate the approved changes.

Public guidance: https://github.com/danarandall/designa11y-design-system
